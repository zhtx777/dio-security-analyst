# Fundamentos de Segurança da Informação

## Vulnerabilidades

Uma vulnerabilidade é uma falha em um sistema, processo ou aplicação que pode permitir que eles tenham comportamentos considerados indesejados. 

## Ameaça

Uma ameaça, é algo que pode explorar uma vulnerabilidade

## Risco

Risco é a combinação entre:
- probabilidade
- impacto

## Principios de Segurança

### Confiabilidade

Garantir que somente pessoas que precisam de uma informação tenham acesso a ela.

### Integridade

Garantir que a informação não sejam modificadas indevidamente

### Disponibilidade

Garantir que os sistemas continuem funcionando

## Boas Praticas

- utilizar uma autentificação forte;
- manter os sistemas sempre atualizados;
- aplicar a politica de menor privilegio;
- sempre monitorar eventos anomalos;
- realizar backups;
- corrigir as vulnerabilidades conhecidas.
